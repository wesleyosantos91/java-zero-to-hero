# Exercícios — Módulo 2

## Básico
1. Criar tabela `produtos` com PK, `NOT NULL` e `CHECK` de preço positivo.
2. Inserir 10 registros.

## Intermediário
1. Criar relacionamento `clientes` ↔ `pedidos`.
2. Consultar top 5 clientes por valor comprado.

## Avançado
1. Criar mini modelagem de escola com 5 tabelas e integridade referencial.
2. Escrever script idempotente de carga inicial.

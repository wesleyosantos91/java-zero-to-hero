# Módulo 1 — Java Orientado a Objetos (Introdução)

## Revisão de entrada
Se você está começando do zero, este módulo vai construir sua base em blocos curtos: sintaxe, lógica, OO e organização.

## O que é Java
- **O que é:** linguagem orientada a objetos e plataforma (JVM).
- **Por que existe:** portabilidade e ecossistema robusto.
- **Problema que resolve:** criar software executável em múltiplos ambientes.
- **Quando usar:** sistemas corporativos, APIs, integrações, batch.
- **Quando evitar:** scripts muito curtos onde custo de setup não compensa.
- **Como funciona (alto nível):** código `.java` → compilação para bytecode → execução na JVM.

## Como estudar Java sem travar
1. Foque em um conceito por vez.
2. Escreva código todo dia, mesmo curto.
3. Erre rápido e corrija com método.
4. Revise semanalmente.

## Exemplo simples
```java
public class OlaMundo {
    public static void main(String[] args) {
        System.out.println("Olá, Java!");
    }
}
```

## Exemplo aplicado
Sistema de cadastro: você criará classes de domínio, validações básicas, persistência e API ao longo da trilha.

## Erros comuns
- Copiar código sem entender.
- Pular fundamentos e ir direto para framework.
- Não testar variações.

## Boas práticas
- Nomear variáveis com intenção.
- Métodos pequenos.
- Comentários para contexto, não para descrever óbvio.

## Fechamento do tópico
- **Resumo:** Java é base para construir aplicações robustas e esta trilha é progressiva.
- **Pontos de atenção:** disciplina de prática e revisão.
- **Checklist:** ambiente pronto, primeiro programa executado, anotações criadas.
- **Exercícios:**
  - Básico: imprimir nome e idade.
  - Intermediário: ler 3 valores e mostrar média.
  - Avançado: mini menu no console com opções.

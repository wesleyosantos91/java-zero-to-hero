## Objetivo do dia
1. entender estrutura de tabela.
2. diferenciar DDL e DML.
3. executar comandos SQL com seguranca.

## Conceito antes do codigo

### DDL
Define estrutura do banco.
Exemplos: `CREATE`, `ALTER`, `DROP`.

### DML
Manipula dados da estrutura.
Exemplos: `INSERT`, `SELECT`, `UPDATE`, `DELETE`.

### Por que essa diferenca importa?
Porque estruturar e manipular sao responsabilidades diferentes.

---

## Bloco 1 - Criar tabela (00:00-00:30)
```sql
CREATE TABLE clientes (
    id NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY PRIMARY KEY,
    nome VARCHAR2(120) NOT NULL,
    email VARCHAR2(160) NOT NULL,
    data_cadastro DATE DEFAULT SYSDATE NOT NULL
);
```

### Por que `PRIMARY KEY`?
Para garantir identificador unico.

### Por que `NOT NULL`?
Para nao permitir dados obrigatorios vazios.

---

## Bloco 2 - Inserir e consultar (00:30-01:10)
```sql
INSERT INTO clientes (nome, email, data_cadastro) VALUES ('Ana Souza', 'ana@email.com', DATE '2026-03-21');
SELECT id, nome, email, data_cadastro FROM clientes ORDER BY nome;
```

### Por que `ORDER BY`?
Para retorno previsivel e legivel.

---

## Bloco 3 - Atualizar e remover com seguranca (01:10-01:40)
```sql
UPDATE clientes SET email = 'ana.novo@email.com' WHERE id = 1;
DELETE FROM clientes WHERE id = 1;
```

### Por que `WHERE` e obrigatorio?
Sem `WHERE`, altera/remove toda a tabela.

# Projeto Prático — Spring Boot CRUD API

## Escopo
API de clientes e pedidos com validação, tratamento global de erros e testes iniciais.

## Critérios de conclusão
- CRUD completo para pelo menos 2 recursos.
- Validação de entrada ativa.
- Erros padronizados em JSON.
- Testes básicos executando com sucesso.

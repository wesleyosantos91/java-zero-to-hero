# Glossario para iniciante

## Java
- JDK: ferramentas para desenvolver e executar Java.
- JRE: ambiente para executar Java.
- JVM: maquina virtual que executa bytecode Java.
- Classe: molde do objeto.
- Objeto: instancia da classe.
- Metodo: acao da classe.
- Atributo: dado da classe.

## OO
- Encapsulamento: proteger dados internos e expor acesso controlado.
- Heranca: reutilizar comportamento de classe base.
- Polimorfismo: mesmo metodo com comportamentos diferentes.
- Abstracao: focar no essencial e esconder detalhe interno.

## SQL
- DDL: linguagem de definicao da estrutura.
- DML: linguagem de manipulacao de dados.
- Tabela: estrutura de dados em linhas e colunas.
- PK: chave primaria, identificador unico.

## REST
- Recurso: entidade de negocio exposta pela API.
- Endpoint: URL da operacao.
- GET: leitura.
- POST: criacao.
- PUT: atualizacao.
- DELETE: remocao.
- JSON: formato textual de dados.

## Spring Batch
- Job: processo batch completo.
- Step: etapa do job.
- Tasklet: unidade de trabalho executada no step.
- JobLauncher: componente que dispara job.
- JobParameters: parametros da execucao do job.

## Docker
- Imagem: modelo de container.
- Container: instancia em execucao da imagem.
- Volume: persistencia de dados.
- Porta: interface de comunicacao com servico.

# Como Usar Esta Formação

## Rotina semanal sugerida
- **Dia A**: leitura ativa + anotações.
- **Dia B**: codificação guiada dos exemplos.
- **Dia C**: exercícios sem consulta.
- **Dia D**: revisão de erros + mini desafio.

## Método de estudo ativo
1. Antes do tópico: escreva o que você já sabe.
2. Durante: implemente e altere exemplos.
3. Depois: explique com suas palavras.
4. Revisão: resolva 3 exercícios sem olhar resposta.

## Critério de domínio por tópico
- Consegue explicar para outra pessoa.
- Consegue implementar do zero.
- Consegue identificar erro comum e corrigir.

# Trilha Completa da Formação

## Visão pedagógica
A trilha segue progressão **simples → aplicado → profissional**. Cada módulo contém:
- revisão estruturada do anterior;
- conceitos com “o que é / por que existe / quando usar”; 
- exemplos pequenos e exemplos reais;
- erros comuns e boas práticas;
- exercícios básicos, intermediários e desafio.

## Módulos
1. **Java OO**: base da linguagem e modelagem.
2. **Oracle SQL**: persistência relacional.
3. **Java + JDBC**: ponte Java ↔ banco.
4. **REST API**: contrato e comunicação HTTP.
5. **Spring Boot**: API completa com camadas.
6. **Spring Batch**: processamento em lote local + Oracle.

## Meta final
Construir, testar e documentar aplicações reais com raciocínio arquitetural inicial.

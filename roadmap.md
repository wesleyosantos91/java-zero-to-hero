# Roadmap de Evolução

## Fase 1 — Base técnica (Módulos 1 e 2)
- Lógica, sintaxe Java, OO e organização de código.
- SQL relacional, modelagem e ambiente Oracle local.

## Fase 2 — Integração de dados (Módulo 3)
- JDBC completo com CRUD, camadas e segurança básica.

## Fase 3 — Comunicação via HTTP (Módulo 4)
- REST em alto nível antes de framework.

## Fase 4 — API profissional (Módulo 5)
- Spring Boot com arquitetura em camadas, DTOs, validação, erros e testes.

## Fase 5 — Processamento em lote (Módulo 6)
- Spring Batch: importação de arquivos para Oracle e exportação Oracle para arquivo.

## Entregáveis de portfólio
- `projects/jdbc-crud-oracle`
- `projects/spring-boot-crud-api`
- `projects/spring-batch-import-export`
